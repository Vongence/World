# World

This repository contains a simple command-line calculator implemented in Python.

## Usage

Run the script with Python 3 and specify the operation followed by two numbers:

```bash
python3 calculator.py <operation> <num1> <num2>
```

Supported operations:

- `add` - addition
- `sub` - subtraction
- `mul` - multiplication
- `div` - division

Example:

```bash
python3 calculator.py add 2 3
```

This will output `5`.
